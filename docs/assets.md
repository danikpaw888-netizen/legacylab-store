# Изображения и демонстрационный ассортимент LegacyLab

## Источники и права

Все 96 файлов `public/images/*.svg`, создаваемые `scripts/generate-catalog.mjs`, — оригинальные программно нарисованные иллюстрации для этого демонстрационного магазина. В них нет фотографий, логотипов или графических элементов сторонних брендов. Внешние изображения при их создании не использовались. Авторские описания и названия демонстрационных товаров созданы для LegacyLab.

Изображения показывают концептуальные товары, а не реально произведённые изделия. Это иллюстрации, а не фотографии. Технические характеристики, состав, посадка и остатки — демонстрационные данные.

Предоставленные пользователю исходники можно изменять и использовать в данном проекте. Отдельная сторонняя лицензия и атрибуция для этих программно созданных SVG не требуются. Эта запись не распространяется на добавленные отдельно фотографии, шрифты или другие активы: их источники должны фиксироваться отдельно.

## Структура каталога

32 товара, 8 подкатегорий, 4 коллекции:
- футболки и лонгсливы;
- худи и свитшоты;
- брюки и джинсы;
- верхняя одежда;
- кроссовки и кеды;
- сумки;
- головные уборы;
- аксессуары.

Для каждого товара созданы три изображения: основной вид, дополнительное графическое исследование и второй цвет. Второе изображение не следует выдавать за документальную фотографию обратной стороны: это альтернативный художественный вид. В модели данных пока нет отдельного соответствия каждой фотографии варианту цвета.

## Воспроизводимость

```sh
node scripts/generate-catalog.mjs
```

Генератор читает восемь файлов `scripts/catalog-data-0.json` — `scripts/catalog-data-7.json`, создаёт:
- `src/catalog.ts`;
- `seed.sql`;
- `public/images/*.svg`.

Генератор перезаписывает только перечисленные создаваемые файлы. Не запускайте его поверх вручную отредактированных иллюстраций без сохранения изменений.

SQL использует `INSERT OR IGNORE`: повторное заполнение не меняет существующие товары, цены и остатки. Цена хранится в целых копейках. Изменение цены или описания в исходном JSON не обновляет уже заполненную базу: для этого используется панель администратора либо отдельная миграция.

## Хранение

SVG включены в исходный код и публикуются вместе с приложением. Ненадёжных временных ссылок нет; сторонний CDN для товаров не требуется. Изображения имеют фиксированные пропорции 900 × 1100 и текстовое описание в `title`. Интерфейс должен дополнительно задавать осмысленный `alt` и размеры при выводе через `img`.

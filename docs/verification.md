## Условия и границы
Публичные проверки выполнены облачным Chromium через Cloudflare Browser Rendering. Геометрия проверена на выбранных страницах, а не на каждой комбинации маршрута и ширины. Не проводились аудит скринридером, проверка реальным iPhone/Safari и измерение Lighthouse/Core Web Vitals. Числовых оценок Lighthouse нет.
Административные изменения проверены локальными интеграционными тестами; на публичном сайте проверён запрет доступа для обычного аккаунта. Общедоступного администратора нет.
Почта не подключена: восстановление пароля сообщает об отсутствии настройки; подтверждения заказов по email не отправляются. Реальных оплат и отправок нет.
Автопроверки и deploy-workflow находятся в GitHub. Для автоматического deploy нужен секрет CLOUDFLARE_API_TOKEN окружения production. Preview с отдельной D1 ещё не включён.
